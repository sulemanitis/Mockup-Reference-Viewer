# Changelog

Notable changes to UI Mockup Reference are documented here.

## [1.0.1] - 2026-10-21

- Added Unity `.meta` files for the package license and changelog.

## [1.0.0] - Initial package version

- Added a dockable Unity Editor window for viewing UI mockup references.
- Added support for assigning a single `Texture2D` or `Sprite`.
- Added batch addition of selected Project-window images.
- Added folder loading for images in a folder and its subfolders.
- Added Previous/Next browsing, Fit, 100% scale, and custom zoom controls.
- Added Ping and Clear actions.
- Added per-project image-list persistence.
- Declared Unity 2022.3 as the minimum Unity version.
